
# FreshHire — Job Discovery Platform

FreshHire is a React-based job discovery web application designed to help users explore job opportunities, filter listings by job type, save favourite jobs, and view detailed job information.

## Live Demo

https://freshhire-job-portal.vercel.app/

## Features

- Browse job listings through a clean interface
- View detailed information for individual jobs
- Filter jobs by job type
- Save favourite jobs using the favourite control
- Explore job titles, companies, locations, salaries, and skills
- Responsive layout for different screen sizes
- Client-side navigation with React Router

## Tech Stack

- React
- JavaScript
- Vite
- React Router DOM
- CSS3
- Git and GitHub
- Vercel for deployment

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/sumitsagar14/freshhire-job-portal.git
   ```

2. Open the project directory:

   ```bash
   cd freshhire-job-portal
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL shown in your terminal.
